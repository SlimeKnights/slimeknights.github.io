Metal Forge UI

The forge allows smelting items in a 2x2 grid into a single item. This can be used for creating alloys, and for forging metalminds.

To forge, fuel needs to be placed in the left-most slot, and a valid recipe placed in the middle slots.

Automation

The forge can be automated using hoppers or other pipes. Inserting into the top will fill the fuel, and each side corresponds to a different input slot. Forged items can be pulled out of the bottom.
