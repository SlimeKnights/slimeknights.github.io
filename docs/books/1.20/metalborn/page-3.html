Casting Metalminds

If you have access to molten metals, metalminds and spikes can also be created in a casting table using the appropriate type of cast. Additionally, copper metalminds can be created in a part builder, which can be sacrificed to create the casts. Alternatively, the part builder can create single use sand casts.
