Randomizing Power

To avoid negative consequences of using spikes, there is another way to use the power. Forging a spike with some nicrosil will create an invested nicrosil nugget, which can be consumed to altar your ferring type.

Invested nicrosil nuggets can only be created using spikes filled from monsters; something about nicrosil spikes conflicts with this process.

Changing Power

To get more control over the metal granted, you can forge the spike with a netherite nugget instead of nicrosil to create other types of invested nuggets. Consuming this nugget changes your ferring type to the type of the spike.

Like invested nicrosil nuggets, invested nuggets created through this process requires spikes filled from monsters.
