Molten Duralumin

Disconnects you from the world.

Entity Effects:

  • 3.0 Magic Damage per level

  • 5 seconds Invisibility per level

Block Effects:

  • Lingering cloud with 5 seconds Invisibility per level

Molten Chromium

If only luck was actually a useful effect, this fluid would be great to drink!

Entity Effects:

  • 2.0 Magic Damage per level

  • 5 seconds Luck per level

Block Effects:

  • Lingering cloud with 5 seconds Luck per level
