Molten Chromium

If only luck was actually a useful effect, this fluid would be great to drink!

Entity Effects:

  • 2.0 Magic Damage per level

  • 5 seconds Luck per level

Block Effects:

  • Lingering cloud with 5 seconds Luck per level

Molten Nicrosil

Nicrosil has an innate pull on magic, seems like a waste to use it like this.

Entity Effects:

  • 3.0 Magic Damage per level

  • 5 seconds Experienced per level

Block Effects:

  • Lingering cloud with 5 seconds Experienced per level
