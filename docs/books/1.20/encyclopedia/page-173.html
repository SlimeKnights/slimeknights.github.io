Earthslime

Earthslime is a portable piston, ideal for simple flying carpets. Well, assuming bricks count as carpet.

Entity Effects:

  • +5 seconds Slowness per level

  • Pulls target with distance based on level

Block Effects:

  • Pulls block

Skyslime

Skyslime is a portable piston, ideal for when you built your base just 1 block away from where it belongs.

Entity Effects:

  • +5 seconds Slowness per level

  • Pushes target with distance based on level

Block Effects:

  • Pushes block
