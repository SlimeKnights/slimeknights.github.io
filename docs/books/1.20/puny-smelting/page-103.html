Extract Defense

Extracting defense modifiers from enchanted books or tools requires earthslime crystals and gold. The process is similarly unstable causing loss of the tool.

Extract Ability

Extracting ability modifiers from enchanted tools is a quite expensive process, requiring not only ichor crystals but also a diamond to help the process. Even with the power of ichor, the tool is still lost.
