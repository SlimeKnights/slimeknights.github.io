Slimeshell

Slimeshells are one part defense, one part storage, granting the best of both shulker abilities.

To create these wondrous pants, pour slime on a shell in a basin.

Properties:

  • Low Armor

  • 0 Defense Slots

  • 3 Upgrade Slots

  • 2 Ability Slots

  • Shell Storage

Slimeboots

These boots take the bounciness of slime to enhance your jumping and movement.

To create these fantastic boots, pour slime on laces in a basin.

Properties:

  • Low Armor

  • 0 Defense Slots

  • 3 Upgrade Slots

  • 2 Ability Slots

  • Bouncy
